## Enhancements/Alternatives

- [BasicV2](https://egonolsen71.github.io/basicv2/)

There is also a Commodore BASIC V2 interpreter/compiler that is written in Java available (GitHub repo located at [basicv2](https://github.com/EgonOlsen71/basicv2)). This looks to be a pretty impressive project that provides cross-compiling support as well as a symbolic 6502 assembler so you can target real C64, VIC20 and possibly even the Commander X16.

- [DotBASIC Plus](https://dotbasic.cbm8bit.com/)

DotBASIC Plus (DB+) is the (self-described) "ultimate software development package" for the Commodore 64. DB+ provides the means to create sophisticated, modern-looking programs and is at the same time perfect for the programming novice.

- [Vision BASIC](https://visionbasic.net/)

I've just watched [this video](https://youtu.be/ROR1NQE-2DY) and this project looks very interesting. (I haven't used it myself, but it certainly looks pretty good.)

- [Simon's BASIC](https://commodore.software/downloads/download/10-basic-extensions/958-simon-s-basic-v3-1)

Adds 114 additional keywords to BASIC 2.0. These included commands to ease the coding of sprites, high-resolution and multi-color graphics, and sound.
